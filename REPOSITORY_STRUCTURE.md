# Repository Structure

- `assets/maps/` — final planning maps
- `assets/charts/` — final analytical charts
- `assets/project-board/` — final project board
- `data/processed/tables/` — authoritative final summary tables
- `data/processed/reporting-rasters/` — final boundary-masked GeoTIFF outputs
- `docs/` — methodology, results, limitations, data sources, contribution and reproducibility notes
- `report/` — final public-facing technical report in PDF and DOCX
